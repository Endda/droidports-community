# DroidPorts Community

Public issue tracker for [DroidPorts.com](https://droidports.com) — the directory of video games running natively on Android.

## What goes here

- **Device compatibility reports** — how a listed port runs on your hardware. Use the *Report Device Test* button on any game page, or [open a report](../../issues/new?template=compatibility-report.yml).
- **Port submissions** — native Android ports we haven't listed yet. [Submit a port](../../issues/new?template=port-submission.yml).

## Ground rules

- No ROMs, disc images, game files, cracked binaries, or unofficial APK mirrors — in issues, comments, or links. They will be removed.
- DroidPorts indexes **native** ports only (decompilations, recompilations, source ports, engine recreations, official releases). Emulators and Winlator/Box64 containers are out of scope.

## Copyright & DMCA

Copyright notices go to `contact@droidports.com` — see the [DMCA procedure](https://droidports.com/terms/#dmca). Please don't file them as issues.
